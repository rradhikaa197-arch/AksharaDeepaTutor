# 📚 Akshara-Deepa Tutor

A self-study companion app for 10th grade (SSLC) students in rural areas.

## 🎯 Problem Statement
After-school learning in rural areas is often unguided. Students lack a way 
to track chapter mastery or identify weak subjects — leading to learning gaps 
that only surface during final exams.

## ✨ Features
- 📋 **Syllabus Tracker** — Track all chapters in Science, Math & Social Studies
- 🧠 **Quiz Mode** — 5-question daily mock tests with 30s timer & answer review
- 🕸️ **Strength Map** — Spider web chart showing subject mastery
- 🎯 **Daily Goal** — Reminder to complete at least one topic per day
- 📴 **100% Offline** — Works without internet after installation

## 🚀 How to Run
1. Clone the repository:
```bash
   git clone https://github.com/rradhikaa197-arch/AksharaDeepaTutor.git
```
2. Open in Android Studio
3. Sync Gradle
4. Run on emulator or device

## 📚 Subjects Covered
- **Science** — Light, Chemical Reactions, Life Processes, Electricity, Magnetism
- **Math** — Real Numbers, Polynomials, Quadratic Equations, AP, Triangles
- **Social** — Resources, Nationalism, Money & Credit, Power Sharing, Democracy

## 🎯 Impact Goals
- 🌟 Quality Education for rural students
- 💻 Digital Literacy through data-driven learning
- 📈 Reduced dropout rates by catching learning gaps early
